# Medix-agent-swarm 医疗助手

这是一个基于多智能体（Agent Swarm）架构的医疗健康助手项目。项目包含了核心的医疗推理大模型微调和多智能体协同诊断系统。

## 项目结构

- **medix-agent-swarm**: 基于多智能体架构的医疗诊断与咨询系统。实现了 Agent Loop 和 Agent Swarm 机制，并结合 Milvus 向量数据库作为知识库。包含：
  - 症状分析、风险评估、指南查询等医疗专属技能
  - 分诊、诊断、研究等多智能体协同 (ConsultationAgent, DiagnosticAgent, ResearchAgent)
  - 结合 Mem0 和 Redis 的长短期记忆机制
- **MediX-R1**: 医疗大模型的相关微调与评估代码，包含模型评估、合并、训练脚本和针对医疗领域优化的奖励函数等。

## 核心特性

- **多智能体协同 (Agent Swarm)**: 包含分诊、诊断、研究等 Agent，模拟真实的医疗会诊流程。
- **丰富的医疗技能 (Skills)**: 涵盖症状分析、风险评估、指南查询、相似病例搜索等专门的医疗能力。
- **长短期记忆机制**: 采用 Mem0 和 Redis 实现了智能体的长期和短期记忆，使得问诊更有连续性。
- **知识库检索 (RAG)**: 集成 Milvus 向量数据库，支持 ICD-10 疾病编码、临床指南、健康生活方式等医学知识的快速检索。
- **模型微调支持**: 提供面向医疗领域的指令微调、DAPO、强化学习 (RL) 等工作流，支持模型能力的持续进化。

## 安装与运行

请分别进入 `medix-agent-swarm` 和 `MediX-R1` 目录，参考其中的详细说明文件进行环境配置和运行。
